# creative-reference-analyzer

## Purpose

Analyze existing visual references and extract reusable design principles.

## Workflow

1. Observe visual structure.
2. Identify composition patterns.
3. Extract style characteristics.
4. Separate essential ideas from decorative details.
5. Convert findings into actionable generation guidance.

## Suitable Scenarios

- competitor visual research
- style exploration
- brand inspiration analysis
- reverse engineering visual language

## Rules

Do not copy a reference image.

Extract:

- design logic
- visual grammar
- communication strategy

## Principle

References are for learning visual thinking, not duplication.
