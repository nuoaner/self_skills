## 4. 标准目录结构

```text
project-name/
  docs/                  # 项目详细文档
  frontend/              # 前端项目，可选
  backend/               # 后端项目，可选
  database/              # 数据库脚本，可选
  scripts/               # 工具脚本、自动化脚本，可选
  tests/                 # 测试代码或测试用例，可选
  .env.example           # 环境变量示例
  README.md              # 项目入口文档
  agent.md               # AI/Agent 协作记录
```

## 5. 目录说明

| 目录 / 文件 | 说明 | 是否必需 |
|---|---|---|
| docs/ | 需求、接口、数据库、部署、测试等详细文档 | 条件必需 |
| frontend/ | 前端页面、组件、路由、接口请求封装等 | 条件必需 |
| backend/ | 后端接口、业务逻辑、数据模型、配置等 | 条件必需 |
| database/ | 建表语句、初始化数据、迁移脚本等 | 条件必需 |
| scripts/ | 开发、部署、数据处理相关脚本 | 可选 |
| tests/ | 自动化测试或测试用例 | 可选 |
| .env.example | 环境变量示例，不包含真实密钥 | 必需 |
| README.md | 项目总说明 | 必需 |
| agent.md | AI/Agent 操作记录 | 必需 |
