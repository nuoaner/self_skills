## 3. 接口详情模板

### API-待填写：接口名称

- 请求方式：`GET / POST / PUT / DELETE`
- 接口地址：`/api/example`
- 功能说明：待填写
- 所属模块：待填写
- 权限要求：无需登录 / 需要登录 / 管理员
- 当前状态：待设计 / 待实现 / 已实现 / 待联调 / 已上线 / 已废弃

#### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|---|---|---|---|---|
| username | string | 是 | 用户名 | admin |

#### 请求示例

```json
{
  "username": "admin",
  "password": "<example-password>"
}
```

#### 返回参数

| 字段名 | 类型 | 说明 | 示例 |
|---|---|---|---|
| code | number | 状态码 | 200 |
| message | string | 提示信息 | success |
| data | object | 返回数据 | {} |

#### 返回示例

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

#### 错误码

| 状态码 | 含义 | 处理方式 |
|---|---|---|
| 400 | 请求参数错误 | 检查请求参数 |
| 401 | 未登录或 token 无效 | 重新登录 |
| 403 | 无权限 | 联系管理员 |
| 500 | 服务端错误 | 查看服务日志 |
