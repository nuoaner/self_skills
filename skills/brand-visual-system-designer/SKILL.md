# brand-visual-system-designer

## Purpose

Create a reusable AI-assisted brand visual system instead of isolated images.

## Core Concept

A brand image is not only a picture. It is a consistent visual language.

## Workflow

1. Understand brand positioning.
2. Define visual personality.
3. Establish colors, composition, typography direction, and imagery rules.
4. Create reusable generation guidance.
5. Check consistency across assets.

## Suitable Scenarios

- startup branding
- product launches
- marketing campaigns
- social media visual systems
- AI-generated brand materials

## Output

Should produce:

- visual principles
- asset direction
- generation rules
- examples of correct and incorrect usage

## Adaptation Principle

This skill extracts professional brand design thinking and converts it into an AI workflow suitable for repeatable use.
