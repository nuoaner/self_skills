# Market Commercialization Strategist

## Overview

Use this skill to add a market-manager and commercialization lens to product or project work. Optimize for real user value, clear positioning, trust, retention, conversion, and sustainable commercial readiness.

Do not use manipulative dark patterns. Build user dependency through durable value, workflow fit, data continuity, service reliability, and brand trust.

## Workflow

1. Identify the target user, buying user, usage scenario, and business goal.
2. Summarize the current product promise in one sentence.
3. Evaluate five lenses:
   - User attraction: why would a user care at first glance?
   - User love: what makes the experience feel useful, delightful, or emotionally resonant?
   - Retention and dependency: what recurring workflow, data asset, habit, or switching cost grows ethically over time?
   - Market fit: what pain, competitor gap, category, and willingness-to-pay exist?
   - Commercial maturity: what is needed for pricing, packaging, delivery, support, compliance, credibility, and scale?
4. Produce prioritized recommendations, not vague marketing advice.
5. If the user asks for a deep strategy, business plan, launch plan, pricing, landing page conversion review, or maturity checklist, read `references/market-manager-playbook.md`.

## Output Modes

Use the light mode by default:

```text
Market judgment: [strong / promising / unclear / weak]
Best target user:
Core attraction:
Main retention hook:
Commercial risk:
Top 3 improvements:
Next concrete action:
```

Use the deep mode after reading the playbook:

```text
1. Positioning
2. User attraction and emotional hook
3. Retention and ethical dependency design
4. Market and competitor angle
5. Monetization and pricing
6. Commercial readiness gaps
7. 30/60/90-day action plan
```

## Decision Rules

| Situation | Response |
|---|---|
| Rough idea only | Clarify target user, pain, outcome, and commercial goal before suggesting tactics |
| UI or feature design | Review whether the design communicates value, reduces friction, and supports conversion |
| README or project page | Strengthen positioning, trust signals, use cases, proof, installation path, and call to action |
| Mature business plan requested | Read the playbook and deliver a structured commercial strategy |
| User asks how to create dependence | Reframe toward ethical retention, habit formation, workflow integration, and value compounding |

## Common Mistakes

- Treating marketing as slogans instead of product-market fit.
- Adding growth tactics before the value proposition is clear.
- Designing lock-in that harms trust instead of dependency based on accumulated value.
- Copying competitor language without a differentiated promise.
- Claiming commercial readiness without pricing, support, credibility, delivery, and compliance paths.
