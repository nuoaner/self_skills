# ai-image-quality-reviewer

## Purpose

Review AI-generated images using design and communication criteria instead of judging only aesthetics.

## Review Dimensions

Evaluate:

- subject accuracy
- composition
- visual hierarchy
- consistency
- usability
- emotional impact

## Workflow

1. Understand intended usage.
2. Compare output against original goal.
3. Identify failure points.
4. Provide actionable improvement directions.

## Suitable Scenarios

- reviewing generated marketing images
- improving prompts
- selecting final assets
- creative iteration

## Principle

A beautiful image that fails its purpose is not a successful output.
