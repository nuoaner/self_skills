# image-prompt-engineer

## Purpose

Convert vague image requests into structured, executable generation instructions.

## Workflow

1. Understand the user's real objective.
2. Extract subject, context, audience and usage.
3. Define composition, style and constraints.
4. Produce a reusable image generation specification.

## Input Problems Solved

Examples:

- "帮我做一个高级感海报"
- "把这个照片变漂亮"
- "做一个品牌图"

Convert them into structured creative requirements.

## Output Structure

Include:

- visual objective
- subject
- environment
- composition
- style direction
- negative constraints
- evaluation criteria

## Principle

Good image generation starts with understanding the problem, not writing longer prompts.
