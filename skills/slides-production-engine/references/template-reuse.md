# Template reuse workflow

1. Run the template inventory before authoring.
2. Identify recurring slide archetypes, layout names, title zones, image zones, footer/source zones, and common shape counts.
3. Map each content unit to an existing archetype when possible.
4. Reuse the visual grammar, not the old topic content.
5. Remove unused slot groups rather than blanking text while leaving decorative remnants.
6. Keep structural work separate from content replacement when editing OOXML.
7. Validate the derived deck with `--original template.pptx`.

Prefer exact reuse for branded or teacher-approved templates. Prefer reconstruction only when the source layout cannot express the new information accurately.
