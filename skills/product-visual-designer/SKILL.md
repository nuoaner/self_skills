# product-visual-designer

## Purpose

Create product-focused visual assets with clear commercial communication goals.

## Core Workflow

1. Understand the product value proposition.
2. Identify target audience and usage channel.
3. Define visual hierarchy.
4. Generate assets matching the business purpose.
5. Review whether the image improves conversion or understanding.

## Suitable Scenarios

- product landing pages
- app screenshots enhancement
- marketing materials
- product announcement images
- e-commerce visual concepts

## Principles

Avoid generating attractive images that hide product information.

Prioritize:

- clarity
- brand consistency
- user understanding
- conversion intent

## Inspiration

Inspired by product photography and AI visual generation workflows.

This repository version focuses on product communication rather than copying any external prompt system.
