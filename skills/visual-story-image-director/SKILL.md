# visual-story-image-director

## Purpose

Transform ordinary images into story-driven visual assets by applying an AI art direction workflow.

This skill is inspired by strong ideas from external image-generation workflows, but is redesigned for `self_skills` as an original capability.

## Core Idea

Do not treat image generation as a style filter.

Use a visual director process:

1. Understand the original scene.
2. Identify important subjects and relationships.
3. Extract emotional signals and visual anchors.
4. Select a suitable visual language.
5. Generate assets with a clear communication purpose.

## Suitable Scenarios

- social media covers
- brand storytelling images
- product narratives
- travel memories
- editorial visuals
- article illustrations

## Output Requirements

Every image request should define:

- subject
- composition
- visual style
- emotional tone
- intended audience
- usage context

## Quality Checks

Avoid:

- replacing the original meaning with random aesthetics
- adding unnecessary objects
- losing important identity elements
- generating beautiful but unusable images

## Inspiration Sources

- gathered-scenes-zine-skill (visual narrative approach)
- editorial design workflows

## Adaptation Principle

Borrow principles, not implementation. This skill maintains an independent workflow and vocabulary for this repository.
