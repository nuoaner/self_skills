# Visual Analysis Framework

Use this reference before choosing a style or writing the final image brief.

## Scene Facts

Record only what the source supports:

- primary subject
- secondary subjects
- objects that carry meaning
- location or environment cues
- foreground / midground / background relationships
- visible light direction and time-of-day clues
- action, gaze, gesture, and body orientation

## Identity Anchors

Ask: if this detail disappeared, would the scene stop feeling like the same moment?

Common anchors:

- face, silhouette, pose, clothing, hairstyle
- product shape, color, logo placement, packaging
- distinctive objects
- recognizable architecture or landscape
- specific interactions between people and objects

Mark anchors as **must preserve**.

## Emotional Residue

Describe what is already present before styling:

- quiet / energetic
- intimate / public
- nostalgic / contemporary
- playful / restrained
- warm / cool

Do not manufacture a dramatic story when the source is intentionally ordinary.

## Reinterpretation Budget

### Low

Identity-sensitive work. Allow crop, palette refinement, subtle texture, restrained framing.

### Medium

Lifestyle and editorial work. Allow controlled collage, material treatment, and layout devices.

### High

Conceptual work where factual fidelity matters less. Still avoid false claims about people, products, places, or events.

## Prompt Construction

Build prompts in this order:

1. source preservation
2. communication goal
3. composition
4. visual language
5. lighting and color
6. graphic devices
7. format
8. avoid list

Keep the story anchored before aesthetics expand.
