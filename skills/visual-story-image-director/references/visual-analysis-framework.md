# Visual Analysis Framework

## Purpose

A reusable framework for analyzing images before generation.

## Analysis Dimensions

### Subject

Identify:
- main subject
- supporting elements
- important details

### Composition

Review:
- focal point
- balance
- perspective
- negative space

### Emotion

Capture:
- atmosphere
- story context
- audience feeling

### Visual Language

Define:
- color direction
- texture
- lighting
- artistic approach

## Rule

Do not copy surface appearance only. Extract the design decisions behind the image.
