# ai-poster-art-director

## Purpose

Design AI-generated posters through an art direction process instead of simple image prompting.

## Workflow

1. Clarify poster objective.
2. Define message hierarchy.
3. Select visual metaphor.
4. Plan composition and typography space.
5. Generate and evaluate communication quality.

## Suitable Scenarios

- event posters
- campaign visuals
- social media promotion
- announcement graphics
- brand storytelling

## Quality Rules

A successful poster should:

- communicate at first glance
- reserve space for text
- match the audience
- maintain visual focus

## Principle

The image is a communication tool, not only an artwork.
