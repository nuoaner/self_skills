# Product Hero Image Case

## Goal

Create a product visual that communicates value quickly.

## Analysis

### Product Focus

What should the viewer understand within three seconds?

### Visual Hierarchy

Priority order:

1. product identity
2. key benefit
3. supporting atmosphere

### Commercial Check

Review:

- Is the product recognizable?
- Is the usage context clear?
- Does the image support conversion?

## Transferable Rule

A commercial image is successful when it improves understanding, not only aesthetics.
