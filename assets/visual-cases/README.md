# Visual Cases Library

Reusable visual learning cases for AI image skills.

## Purpose

This directory stores examples, references, and analysis records.

The goal is not to collect images, but to extract reusable visual principles.

## Case Structure

Each case should contain:

- source image or reference
- generated result (when applicable)
- analysis.md

## Analysis Focus

- composition
- subject relationship
- color strategy
- emotional intent
- usage scenario
- transferable design rules
